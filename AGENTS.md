## CtrlPlusLLC central AI collaboration policy

Before coding or opening a PR, retrieve and read `CtrlPlusLLC/infrastructureGuidelines/AGENTS.md` from its default branch using authenticated GitHub access (or a local checkout). If unavailable, report that; do not claim compliance. Follow its independent review, PR handoff, and resumption rules alongside any repository-specific guidance. Preserve local instructions and flag conflicts.
